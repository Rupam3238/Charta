# Charta logo asset package

Concept: 5 — single continuous C-shaped handwritten stroke integrated with a subtle page/document silhouette.

## Geometry
- Master SVG viewBox: 0 0 1024 1024
- Transparent background.
- Page silhouette: restrained rounded document contour.
- C gesture: one continuous cubic Bézier path with round caps/joins.
- Accent terminal is an exact subsegment of the same C geometry, not a separate decorative stroke.
- No bitmap, gradient, shadow, 3D effect, pen/pencil/nib, or embedded image.

## Colors
- Dark ink: #182233
- Charta accent: #536DFE
- Subtle page neutral: #D9DDE4
- Desktop icon background: #F4F6F8

## Files
- svg/: color, monochrome, and padded SVG masters
- png/: 16 through 1024 px transparent PNG exports
- favicon/: SVG + 16/32/48 PNG
- app-icon/: transparent, padded-transparent, and desktop-background 512/1024 PNGs
- svg/charta-logo-color-padded-background.svg: padded desktop-icon source with neutral background
- print/: PDF and EPS color/monochrome vectors
